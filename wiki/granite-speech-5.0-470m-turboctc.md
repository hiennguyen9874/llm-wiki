Granite Speech 5.0 470M TurboCTC (`ibm-granite/granite-speech-5.0-470m-turboctc`) is IBM's compact ~470M-parameter English-only offline ASR model that pairs a Conformer acoustic encoder (block self-attention, self-conditioning, 8x temporal downsampling) with a 16,384-unit BPE CTC head decoded non-autoregressively and greedily, targeting low-latency/high-throughput enterprise transcription on laptops, smartphones, and other edge devices (**Reported**).[^granite-turboctc-card]

## Architecture

- 16 Conformer blocks trained with Connectionist Temporal Classification (CTC) and a 16,384-BPE classification head; inference is non-autoregressive greedy decoding (**Reported**).[^granite-turboctc-card]
- Temporal subsampling by 8x reduces frame rate from 100 Hz to 12.5 Hz: first by stacking and skipping consecutive log-mel plus delta frames (2x), then strided convolutions and pooled residuals in the first two Conformer blocks (4x) (**Reported**).[^granite-turboctc-card]
- Encoder uses block self-attention with 128-frame blocks and self-conditioned CTC from the middle layer (**Reported**).[^granite-turboctc-card]
- Configuration table (**Reported**):[^granite-turboctc-card]

| Configuration parameter | Value |
| --- | --- |
| Input dimension | 320 (80 logmels + 80 deltas) x 2 |
| Nb. of layers | 16 |
| Hidden dimension | 1024 |
| Nb. of attention heads | 8 |
| Attention head size | 128 |
| Attention block size | 128 |
| Convolution kernel size | 7 |
| Output dimension (BPE) | 16384 |

## Training data

- Total claimed is approximately 60,000 hours of English audio from public corpora; the itemized table sums to 57,710 hours before synthetic additions (sum is **Synthesis** from the card's row values): CommonVoice-17 2,500 h, MLS 44,600 h, LibriSpeech 960 h, VoxPopuli 500 h, YODAS 8,900 h, AMI 150 h, Earnings-22 100 h (**Reported**).[^granite-turboctc-card]
- Three synthetic additions (**Reported**):[^granite-turboctc-card]
  - 2,000 h of multi-speaker data from concatenating single-speaker segments of MLS, YODAS, CommonVoice-17, VoxPopuli, and AMI.
  - 500 h of multi-speaker data from concatenating single-speaker Earnings-22 segments.
  - 240 h of numeric-heavy utterances (numbers, currencies, website names, phone numbers, addresses, decimal points/dots) with text generated by `gpt-oss-120b` or `gpt-oss-20b` and audio synthesized with StyleTTS2.
- No dataset revision pins, split definitions, filtering rules, or consent/quality notes are stated in the card (**Observed** by static inspection).[^granite-turboctc-card]
- Infrastructure: trained on IBM's Blue Vela cluster (NVIDIA H100 GPUs); this model completed in 10 days on 8 H100 GPUs (**Reported**).[^granite-turboctc-card]

## Inference and usage

- Transformers path requires `transformers>=5.16.0` plus `datasets`; load with `AutoProcessor.from_pretrained(model_id)` and `AutoModelForCTC.from_pretrained(model_id, device_map="auto")`, then `processor(...)` inputs moved to the model device and dtype, `model.generate(**inputs)`, and `processor.batch_decode(outputs, skip_special_tokens=True)`; the processor's `device` argument computes the log-mel front-end on the model's accelerator to save a host-to-device copy (**Reported**).[^granite-turboctc-card]
- Apple Silicon path uses `mlx-audio` 0.5.1 or later: `python -m mlx_audio.stt.generate --model ibm-granite/granite-speech-5.0-470m-turboctc --verbose --audio "audio.wav" --output-path "transcript"` (**Reported**).[^granite-turboctc-card]
- transcribe.cpp path runs a pre-quantized GGUF with no Python at runtime on Metal, Vulkan, CUDA, ROCm, or CPU: fetch `granite-speech-5.0-470m-turboctc-Q8_0.gguf` from `handy-computer/granite-speech-5.0-470m-turboctc-gguf`, then `build/bin/transcribe-cli -q -m models/granite-speech-5.0-470m-turboctc-Q8_0.gguf samples/love-loss.wav` (**Reported**).[^granite-turboctc-card]
- No usage command was executed and no transcription output reproduced in this ingest (**Synthesis**).[^granite-turboctc-card]
