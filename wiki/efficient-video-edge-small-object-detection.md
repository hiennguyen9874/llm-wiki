## Image to video through memory and dynamic compute

### SAM 2 streaming memory for promptable video segmentation

- **Reported:** SAM 2 generalizes SAM to video: per-frame Hiera image encoder run once, then L=4 memory-attention blocks condition current-frame features on memory-bank spatial features plus object-pointer tokens before a SAM-style lightweight mask decoder; image embeddings are reused for memory via a convolutional memory encoder that fuses downsampled mask plus unconditioned frame embedding[^sam2-2408-00714-v2-1].
- **Reported:** Memory bank is two FIFO queues — up to N recent unprompted frames (default N=6, 64-dim projection) plus up to M prompted frames — with temporal position on recent frames only; object pointers are 256-dim decoder mask tokens split into 4×64 for cross-attention, plus an occlusion head/token and learned occlusion embedding for frames where the object is absent[^sam2-2408-00714-v2-2].
- **Reported:** Training is joint image+video with alternating batches (~15.2% SA-1B / ~70% SA-V / ~14.8% Internal; OSS mix adds DAVIS/MOSE/YouTubeVOS); it simulates interaction on 8-frame clips with up to 2 prompted frames, initial prompt GT-mask 0.5 / click 0.25 / box 0.25 plus corrective clicks, focal+dice 20:1 plus MAE-IoU and cross-entropy-occlusion 1:1:1, plus 16-frame fine-tune on most-edited masklets with frozen encoder[^sam2-2408-00714-v2-3].
- **Reported:** SA-V is 50.9K videos / 196.0 hr / 4.2M frames with 190.9K manual masklets (10.0M masks, 42.5% disappearance) and 642.6K masklets with auto (35.5M masks, 27.7% disappearance); val is 155 videos/293 masklets and test 150/278, annotated Phase-1 style at 6 FPS on challenging fast/occluded/reappearing targets[^sam2-2408-00714-v2-4].
- **Reported:** Data engine: Phase 1 SAM-per-frame 37.8 s/frame (1.4K videos/16K masklets); Phase 2 SAM+SAM-2-Mask temporal propagation 7.4 s/frame (~5.1×, 63.5K masklets); Phase 3 full SAM 2 refinement clicks 4.5 s/frame (~8.4×, 197.0K masklets), with separate verification pass plus grid-prompted auto masklets for coverage and failure mining[^sam2-2408-00714-v2-5].
- **Reported:** Zero-shot interactive PVS on 9 datasets (3 clicks/frame, offline error-selected and online single-pass): SAM 2 dominates SAM+XMem++ and SAM+Cutie across 1–8 interacted frames with >3× fewer interactions for the same J&F; first-frame-only on 17 datasets averages 64.7/75.3/77.6 (1/3/5 clicks), 74.4 box, 79.3 mask versus 56.9/68.4/70.6/67.6/72.7 and 56.7/70.1/72.2/69.4/74.1[^sam2-2408-00714-v2-6].
- **Reported:** Semi-supervised VOS SOTA (first-frame GT mask): Hiera-B+ / Hiera-L reach MOSE-val 76.6/77.9, DAVIS17-val 90.2/90.7, LVOS-val 78.0/78.0, SA-V val 76.8/77.9, SA-V test 77.0/78.4, YTVOS19-val 88.6/89.3 at 43.8/30.2 FPS A100 batch-1; prior best in the same table is Cutie-base+ 71.7/88.1/–/61.3/62.8/87.5, showing the largest gap on open-world SA-V[^sam2-2408-00714-v2-7].
- **Reported:** Ablations (512-res, 3-click J&F): data mix matters — VOS-only 48.1 SA-V-val / 59.7 9-zero-shot versus Internal+SA-V+SA-1B 63.6/71.6 and full+VOS 63.1/71.6 with SA-23 58.9; quantity follows a power law; 50K most-edited beats 50K random (66.2 vs 63.7 SA-V-val) but full 190K still wins; architecture defaults are 1024-res, 8 frames, N=6 memories, B+ encoder, 2D-RoPE, object pointers (helps SA-V-val/LVOSv2), no GRU gain[^sam2-2408-00714-v2-8].
- **Reported:** Stated limits: shot-change failure, crowded-scene confusion, long occlusion / long-video drift, thin fast-moving detail loss, similar-appearance distractors (explicit motion modeling suggested); multi-object runs per-object memory/decoder with shared image features only, no inter-object communication[^sam2-2408-00714-v2-9].
- **Synthesis:** reusable pattern is `once-per-video encoder + FIFO spatial memory with prompted-frame pinning + pointer/occlusion side-channel`, replacing decoupled SAM-plus-tracker composition; the prior secondary row claiming ~6× faster than SAM is now grounded as 130.1 vs 21.7 FPS on the SA image task[^sam2-2408-00714-v2-10].
- **Reported:** CAVIS (ICCV 2025, Paper ID 8006) targets instance-association failures under occlusion and similar-looking objects by adding around-instance context to center-only matching; the motivating example is keeping a bicycle identity through occlusion by using rider/bicycle surroundings[^cavis-2407-03010-v2-1].
- **Reported:** Its Context-Aware Instance Tracker (CAIT) builds surrounding features by average-filtering pixel-decoder maps (9×9) inside Laplacian-filtered mask boundaries, then fuses them with core Mask2Former instance features via a 3-layer MLP; the fused features are trained with a context contrastive loss[^cavis-2407-03010-v2-2].
- **Reported:** For tracking, CAVIS keeps a 6-block transformer tracker but uses context-aware features as query/key in cross-attention while retaining core instance features as value; surrounding features are reordered by Hungarian matching on core-feature cosine similarity so context stays attached to the right identity[^cavis-2407-03010-v2-3].
- **Reported:** Its Prototypical Cross-frame Contrastive (PCC) loss forms per-instance prototypes by mask-averaged pixel-decoder embeddings and contrasts them across frames, enforcing region-level consistency without per-pixel memory[^cavis-2407-03010-v2-4].
- **Reported:** With ResNet-50, CAVIS reports OVIS 37.6, YTVIS19 55.7, and YTVIS21 50.5 AP, ahead of the previous best in the paper's table; with Swin-L it reports 48.6/66.0/61.1 and with ViT-L 53.2/68.9/64.6, rising to 57.1/69.4/65.3 with the temporal refiner[^cavis-2407-03010-v2-5].
- **Reported:** On VIPSeg video panoptic segmentation it reports ResNet-50 45.3 VPQ / 45.3 STQ and ViT-L 58.5 VPQ / 56.1 STQ with the refiner, with the largest gains on `thing' classes; on long-video YTVIS22 it reports 38.6 AP versus 37.5 GenVIS and 37.2 DVIS++ with the same backbone[^cavis-2407-03010-v2-6].
- **Reported:** OVIS ResNet-50 ablations attribute the gain to both losses (MinVIS baseline 26.4 → 30.0 with both), context-aware matching (35.3 → 37.6), 9×9 average filtering (best among 3–11), 3 training frames (best among 2–4), correct context alignment (33.2 → 37.6), and core-feature values (37.6 vs 36.8 with fused values)[^cavis-2407-03010-v2-7].
- **Reported:** Inference cost is 85.6 ms versus 78.9 DVIS and 80.1 GenVIS on 2080Ti with ResNet-50 in the paper's setup; stated limits are dependence on segmenter mask quality, homogenization from oversized context, degradation with wider frame gaps, and surveillance-privacy caution[^cavis-2407-03010-v2-8].
- **Synthesis:** reusable direction is `state/memory + cached feature + dynamic computation` rather than running an image detector independently per frame; CAVIS adds a memory-efficient alternative to full-context memories such as CAROQ by restricting context to object boundaries plus prototype-level cross-frame consistency.

### Temporal-aware Query Routing for decoder-layer skipping

- **Reported:** Online-VIS profiling on MinVIS attributes ~45% of time to the image encoder (backbone 17% + FPN 28%), ~52% to the transformer decoder, and ~3% to the Hungarian tracker, motivating decoder optimization over encoder pre-training or FPN redesign[^tar-iccv2025-cheng-1].
- **Reported:** A cross-layer probe matching prior-frame layer-m with current-frame layer-n outputs against ground truth finds moderate compute beats full compute (`3+1` at 82.68 mIoU versus `9+9` at 81.58 mIoU), which the paper uses as evidence of redundant decoder layers[^tar-iccv2025-cheng-1].
- **Reported:** TAR is inserted before each decoder layer after M^s warm-up layers: a Synchronizer cross-attention plus LayerNorm aligns current queries to the previous frame's final queries, then a per-layer Router MLP on concat(current, previous, difference) predicts per-query N x 2 scores summed to one global binary skip/run score, with argmax replaced during training by a straight-through softmax trick; every decoder layer stays supervised so any routed depth is a usable output[^tar-iccv2025-cheng-2].
- **Reported:** ResNet-50 YouTubeVIS Tab. 1 (3090, frame-by-frame): TAR+MinVIS 40.5 to 28.9 ms / 24.7 to 34.6 FPS with YTVIS19 47.4 to 48.4 AP and YTVIS21 44.2 to 44.3 AP; TAR+DVIS++ 44.7 to 30.5 ms / 22.4 to 32.8 FPS with 55.5 to 55.7 and 50.0 to 50.8 AP. Large backbones gain less: TAR+MinVIS 63.2 to 54.1 ms / 15.8 to 18.5 FPS and *TAR+DVIS++ 135.9 to 124.7 ms / 7.4 to 8.0 FPS[^tar-iccv2025-cheng-3].
- **Reported:** OVIS Tab. 2: ResNet-50 TAR+MinVIS 25.0 to 27.4 AP (AP75 24.0 to 27.1, AR10 29.7 to 33.2) and TAR+DVIS++ 37.2 to 38.1 AP with an AP75 regression (37.3 to 36.2); large-backbone TAR+MinVIS 39.4 to 40.6 and *TAR+DVIS++ 49.6 to 50.2 AP, again with small AP75 regressions[^tar-iccv2025-cheng-4].
- **Reported:** Ablations on YTVIS19: Router without Synchronizer gives only +2.8 FPS at 47.4 to 45.1 mAP; bipartite-match sync plus Router reaches 31.3 FPS / 46.4 mAP while learnable cross-attention sync plus Router reaches 34.6 FPS / 48.4 mAP; FlashAttention-2 (+3.1 FPS) and op fusion (+2.5 FPS) are additive, with standalone TAR at 31.7 FPS / 48.5 mAP and all three at 34.6 / 48.4; M^s = 1 is best because routing search space is 2^(M-M^s); fixed 6-layer MinVIS (29.7 FPS / 47.6 mAP) beats fixed 9-layer but loses to adaptive TAR (34.6 / 48.4)[^tar-iccv2025-cheng-5].
- **Reported:** Retained decoder depth tracks inter-frame change (hqytvis val RGB-MSE versus non-skipped layers, Fig. 5); MinVIS training freezes the encoder on adjacent-frame pairs (AdamW 5k at 1e-4 + 1k at 1e-5, batch 8, no COCO pseudo-video) while DVIS++ freezes a CTVIS-initialized segmenter on 5-frame clips (20k OVIS / 40k YTVIS iters, decay at 14k/28k, COCO extra only for YTVIS)[^tar-iccv2025-cheng-6].
- **Synthesis:** reusable online-VIS pattern is `short warm-up + cross-attention query sync + difference-aware per-layer skip with straight-through routing`, preferable to fixed layer pruning because redundancy varies with inter-frame change; budget the headline 34.6 FPS as TAR plus FlashAttention-2 plus op fusion rather than routing alone.

### SAM 3 detector-tracker and Multiplex for multi-object video

- **Reported:** SAM 3 couples a per-frame DETR concept detector with a SAM-2-style tracker sharing one PE backbone run once per frame: propagate prior masklets, detect new objects, IoU match-and-update with masklet detection-score suppression and periodic high-confidence re-prompting. Three masks per object handle ambiguity; clicks refine single masklets[^sam3-2511-16719-v2-20].
- **Reported:** Promptable Visual Segmentation improves over SAM 2.1: VOS J&F MOSEv1 78.4, DAVIS17 92.2, LVOSv2 88.5, SA-V val 83.5 / test 84.4, YTVOS19 G 89.7, MOSEv2 J&F-dot 60.3 (+6.5 over prior best 53.8); interactive SA-37 mIoU 66.1/81.3/85.1 at 1/3/5 clicks at 43.5 FPS. Video PCS reaches VEval SA-V 30.3/58.0, YT-Temporal-1B 50.8/69.9, SmartGlasses 36.4/63.6 cgF1/pHOTA[^sam3-2511-16719-v2-21].
- **Reported:** Training on SA-Co/VIDEO masklets as Stage-4 VOS data lifts VEval plus DAVIS/SA-V J&F with more masklets (e.g. VEval SA-V 84.9 to 86.5, YT-1B 80.7 to 81.4)[^sam3-2511-16719-v2-21].
- **Reported:** SAM 3 Multiplex (appendix) replaces per-object memory passes with bucketed shared memory: fixed M=16 slots per bucket, mux/demux between object and bucket space, shared spatial memory plus per-object identity embeddings, 3 masks and 5 tokens per slot (80 tokens/bucket). Complexity drops from O(N) to O(ceil(N/M)) forward passes[^sam3-2511-16719-v2-22].
- **Reported:** Multiplex preserves or improves quality while scaling: VEval YT +2.7 cgF1 / +0.9 pHOTA, OVIS +1.8 mAP with small regressions on LVVIS/BURST/YTVIS21; VOS +2.0 MOSEv2 (60.3 to 62.3), +1.2 MOSEv1, gains on 6/7 suites. H100 throughput has ~7% single-object overhead but 5.2x at 128 objects with crossover at >=2 objects[^sam3-2511-16719-v2-22].
- **Reported:** Stated video limits: cost linear in objects without Multiplex (needs 2/4/8 H200s for 10/28/64 objects at 30 FPS), no shared object-level context for crowded ambiguity, and hard concept/instance mode-switch[^sam3-2511-16719-v2-23].
- **Synthesis:** for multi-object video prefer `once-per-frame encoder + detect-plus-propagate-plus-match` with shared bucketed memory over per-object memory paths; SAM 3 shows the detector quality plus re-prompting matters as much as the propagator on large-vocabulary VEval.

### AutoQ-VIS quality-guided self-training for unsupervised VIS

- **Reported:** AutoQ-VIS (WACV 2026 ID 2136) tackles the VideoCutLER synthetic-to-real gap: prior unsupervised VOS handles single foreground, OCLR fixes object count, flow-based methods depend on human-supervised RAFT, and VideoCutLER removes flow via spatial augmentation of CutLER ImageNet pseudo-labels but keeps static configurations without natural motion or appearance variation[^autoqvis-2512-06864-v1-1].
- **Reported:** Initial stage jointly trains VideoMask2Former-ResNet-50 (initialized from VideoCutLER weights) plus a Mask Scoring R-CNN-inspired quality predictor — four 3×3 convolutions with final stride-2 reduction plus three fully-connected layers fusing pixel-decoder features and mask prediction to regress mask IoU with L2 loss; the paper stresses using raw mask logits because 0.5-binarized masks yield no meaningful output[^autoqvis-2512-06864-v1-2].
- **Reported:** Each self-training round generates pseudo-labels at confidence ≥0.25, applies spatiotemporal NMS (suppress lower-confidence box if mask IoU ≥0.5 in any frame), scores per-frame quality as Q = predicted IoU × class confidence, keeps frames with Q ≥ τ_th, resets VIS weights to the initial model, keeps the predictor frozen, samples batches 50/50 synthetic versus pseudo-labeled, and trains on 3-frame clips drawn only from fully-selected frames while persisting all labels for progressive refinement[^autoqvis-2512-06864-v1-3].
- **Reported:** Mask-head DropLoss zeroes loss when max ground-truth overlap ≤0.01, reintroduced from CutLER after its absence in VideoCutLER; adaptive fusion bulk-inserts new videos and frame-wise merges overlapping tracks (IoU ≥0.5 any frame), preferring the new mask except when only the old label was selected[^autoqvis-2512-06864-v1-3].
- **Reported:** Training uses synthetic plus unlabeled YouTubeVIS-2019 train (2,238 train / 302 val / 343 test videos at 6 FPS), class-agnostic AP/AR on val: initial 8,000 iterations on 1×V100 (batch 2, lr 2e-5), each self-training round 10,000 iterations on 2×V100 (batch 4, lr 2e-5), best at 2 rounds and τ_th=0.75[^autoqvis-2512-06864-v1-7].
- **Reported:** YouTubeVIS-2019 val reaches 52.6 AP_50 / 28.2 AP_75 / 28.1 AP / 6.7 AP_S / 21.2 AP_M / 40.7 AP_L / 42.5 AR_10 versus reproduced VideoCutLER 48.2/22.9/24.5/6.7/17.7/36.3/42.3 (+4.4 AP_50, +5.3 AP_75, gains on medium/large only); the reproduced baseline is below the VideoCutLER paper 50.7 because that number is train-split while this is val-split[^autoqvis-2512-06864-v1-4].
- **Reported:** Oracle gaps remain large: fully-supervised theoretical limit 76.8 AP_50 / 46.8 AP and perfect-selection practical limit (all IoU ≥0.5 pseudo-labels) 62.7 AP_50 / 33.9 AP, leaving ~10.1 AP_50 headroom for better pseudo-label utilization[^autoqvis-2512-06864-v1-4].
- **Reported:** Component ablations attribute +4.6 AP_50 to DropLoss (48.0 without), +3.4 to freezing the predictor (49.2 without), +2.9 to adaptive fusion (49.7 without), +2.1 to the quality predictor over confidence-only selection at τ=0.85 (50.5 without, still +2.3 over VideoCutLER), and +1.0 to per-round weight reset (51.6 without); quality score Spearman ρ_s=0.57 versus confidence 0.42 against ground-truth IoU[^autoqvis-2512-06864-v1-5].
- **Reported:** Round and threshold sweeps peak at 2 rounds (1: 51.3, 2: 52.6, 3: 52.0 from noise accumulation) and τ_th=0.75 (0.95: 48.7, 0.85: 48.8, 0.75: 52.6, 0.50: 52.4)[^autoqvis-2512-06864-v1-5].
- **Reported:** On crowded UVO-Dense (759 Kinetics-400 videos at 30 FPS, 503 train / 256 val, ~7× instances per video) with τ_th lowered to 0.3, AutoQ-VIS reaches 14.6 AP_50 / 7.0 AP versus VideoCutLER 13.5/6.2 (+1.1 AP_50)[^autoqvis-2512-06864-v1-6].
- **Reported:** Stated limits are fixed τ_th and round count needing per-dataset tuning, frame-level quality without temporal consistency, slight quality overestimation on large objects with a large-biased pseudo area distribution that stays stable across rounds, and zero AP_S gain[^autoqvis-2512-06864-v1-6].
- **Synthesis:** reusable unsupervised-VIS pattern is `synthetic bootstrap + frozen IoU predictor × confidence + spatiotemporal NMS + threshold-and-fuse + retrain with reset`, complementary to memory/tracker advances in SAM 2, CAVIS, and SAM 3; DropLoss and predictor-freezing are the highest-leverage guards against pseudo-label error amplification.

## Edge and mobile as first-class objectives

- **Reported:** DEIMv2 (arXiv `2509.20787v4`) is now compiled from its primary paper: ultra-light variants prune HGNetv2-B0 by depth and width — Pico drops stage 4 to keep outputs only to 1/16, Femto cuts Pico last-stage blocks from two to one, Atto further shrinks that block from 512 to 256 channels; reported COCO `val2017` is Nano 43.0 AP (3.57M, 6.86 GFLOPs, 640px, 2 scales, 300 queries), Pico 38.5 AP (1.51M, 5.15 GFLOPs, 640px, 200 queries), Femto 31.0 AP (0.96M, 1.67 GFLOPs, 416px, 150 queries), and Atto 23.8 AP (0.49M, 0.76 GFLOPs, 320px, 100 queries)[^deimv2-2509-20787-v4-1][^deimv2-2509-20787-v4-2].
- **Reported:** Pico matches reported YOLOv10-N 38.5 AP with about 1.5M versus 2.3M params (~50% fewer in the paper's wording), and Atto matches NanoDet-M despite its smaller size; FGL plus DDF local loss is excluded for Pico/Femto/Atto because weak small-model teachers degrade self-distillation[^deimv2-2509-20787-v4-2].
- **Reported:** YOLO26n is reported at 40.9 AP (40.1 e2e) with 38.9 ms CPU ONNX and 1.7 ms T4 TensorRT FP16 at 2.4M params / 5.4 GFLOPs; the full detection family scales to X at 57.5 AP (56.9 e2e), 525.8 ms CPU / 11.8 ms T4, 55.7M / 193.9 GFLOPs, with S/M/L points tabulated in the independent analysis paper[^yolo26-2509-25164-v5-1][^yolo26-2509-25164-v5-2].
- **Reported:** YOLO26 edge readiness comes from DFL-free regression plus NMS-free head: leaner graph, faster cold-start, fewer runtime dependencies, and clean export to ONNX, TensorRT, CoreML, TFLite, and OpenVINO without DFL/NMS special-casing; paper reports stable accuracy under FP16 and INT8 quantization, outperforming YOLOv11/YOLOv12 under identical quantization, and targets Jetson Orin/Nano, Snapdragon, ARM CPUs, and smart cameras[^yolo26-2509-25164-v5-3].
- **Reported:** multi-task efficiency at 640 px unless noted — instance segmentation e2e box/mask AP from N-seg 39.6/33.9 (53.3 ms CPU / 2.1 ms T4, 2.7M/9.1B) to X-seg 56.5/47.0 (787.0 ms / 16.4 ms, 62.8M/313.5B); pose e2e mAP50–95 from 57.2 (N-pose) to 71.6 (X-pose); OBB on DOTA v1 at 1024 px from 52.4 mAP50–95 (N-obb, 97.7 ms CPU / 2.8 ms T4) to 56.7 (X-obb); ImageNet classification at 224 px Top-1 from 71.4 (N-cls) to 79.9 (X-cls) with T4 latency below 4 ms[^yolo26-2509-25164-v5-4].
- **Reported:** Ultralytics documentation extends the task matrix with semantic segmentation and monocular depth across N/S/M/L/X. On Cityscapes at 1024×2048, semantic N→X spans 78.3→83.6 mIoU at 4.4→48.9 ms RTX 3090 PyTorch; on NYU Depth V2 at 768 px, depth N→X spans delta1 0.882→0.933, abs_rel 0.109→0.080, RMSE 0.414→0.344, and 2.7→13.6 ms T4 TensorRT10[^ultralytics-yolo26-doc-9f4ac453-2].
- **Reported:** YOLOv11 spans nano to xlarge for edge-to-high-performance deployment with cloud, edge-device, and NVIDIA-GPU adaptability; the overview reports YOLOv11m above YOLOv8m COCO mAP with 22% fewer parameters as its parameter-efficiency evidence[^yolo11-2410-17725-v1-2].
- **Reported:** YOLOv11 task heads cover detection, `-seg`, `-pose`, `-obb`, and `-cls` across the same nano-to-xlarge scales, each supporting inference, validation, training, and export[^yolo11-2410-17725-v1-3].
- **Reported:** RF-DETR-Seg (arXiv `2511.09554v2`) is now compiled from its primary paper: it adds a lightweight mask branch that bilinearly upsamples the same low-resolution encoder map used for detection, learns a projector to pixel embeddings, and dots per-decoder-layer query embeddings (via FFN) with that map; it omits multi-scale backbone features unlike MaskDINO to save latency and is pretrained on Objects-365 pseudo-labeled with SAM2 masks[^rfdetr-2511-09554-v2-1].

## Small objects remain open

- **Reported:** DEIMv2 primary evidence sharpens the small-object gap: versus DEIM at similar params/FLOPs, medium/large AP rises clearly while small AP barely moves (S 30.4 to 31.4 AP_S versus 52.6 to 55.3 AP_M and 65.7 to 70.3 AP_L; X 39.2 AP_S with 62.9 AP_M/75.9 AP_L), which the paper attributes to DINOv3 strong global semantics with limited fine-grained detail[^deimv2-2509-20787-v4-2].
- **Reported:** YOLO26 addresses small targets with STAL prioritized assignment plus ProgLoss progressive rebalancing for tiny/occluded instances under clutter, foliage, or motion blur. Ultralytics documentation confirms `yolo26-p2.yaml` for a small-object head and `yolo26-p6.yaml` for large-input detection, but both are architecture-only: no scale-specific P2/P6 weights are released, so a scaled YAML must be instantiated and trained or fine-tuned[^yolo26-2509-25164-v5-3][^ultralytics-yolo26-doc-9f4ac453-2].
- **Reported:** YOLOv11 adds C2PSA spatial attention after SPPF and in the neck/head path to concentrate on key regions, which the overview presents as help for smaller or partially occluded objects versus YOLOv8[^yolo11-2410-17725-v1-1].
- **Reported:** AutoQ-VIS leaves small objects unsolved in unsupervised VIS: 6.7 AP_S ties VideoCutLER despite +3.5 AP_M and +4.4 AP_L, consistent with its large-biased pseudo-label area distribution and quality-score overestimation on large masks[^autoqvis-2512-06864-v1-6].
- **Synthesis:** high-resolution features, adaptive tiling, pyramids, query initialization, assignment, and joint super-resolution plus detection remain fertile because aerial, surveillance, and inspection failures persist after overall AP gains.
