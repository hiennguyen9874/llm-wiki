# CoCoOp conditional context optimization

Conditional Context Optimization (CoCoOp) extends CoOp's continuous CLIP prompt context with an image-conditioned offset generated by a small Meta-Net. It retains frozen CLIP encoders and few-shot supervision, but makes the text classifier prompts instance-specific; the paper reports substantially better base-to-new-class generalization than static CoOp prompts, with added training and memory cost.[^zhou-2022-cocoop]

## Method

- CoCoOp starts with $M$ shared learnable context vectors and a frozen CLIP image encoder and text encoder. For an image feature $x$, a Meta-Net produces one vector $\pi=h_\theta(x)$, which is added to every context vector: $v_m(x)=v_m+\pi$. The prompt for each candidate class therefore depends on the image, while retaining that class's name tokens.[^zhou-2022-cocoop]
- The Meta-Net is a two-layer Linear-ReLU-Linear bottleneck whose hidden layer reduces the image-feature dimension by 16 times. Training updates the context vectors and Meta-Net parameters with classification cross-entropy; it leaves the pretrained CLIP model frozen.[^zhou-2022-cocoop]
- The reported configuration uses CLIP ViT-B/16, four context tokens initialized from “a photo of a,” 16 labeled images per class, batch size 1, and 10 epochs. These are experimental settings, not requirements of the method.[^zhou-2022-cocoop]

## Reported findings

- In base-to-new-class evaluation across 11 datasets, CoCoOp averaged 80.47% on base classes, 71.69% on new classes, and a 75.83% harmonic mean. The corresponding CoOp results were 82.69%, 63.22%, and 71.66%; zero-shot CLIP scored 69.34%, 74.22%, and 71.70%. The comparison trades some base-class accuracy for stronger unseen-class performance under the paper's protocol.[^zhou-2022-cocoop]
- When prompts learned on ImageNet were transferred to ten target datasets, CoCoOp averaged 65.74% versus CoOp's 63.88%, although it was slightly lower on the ImageNet source (71.02% versus 71.51%). In ImageNet-based domain generalization, CoCoOp exceeded CoOp on ImageNet-Sketch, ImageNet-A, and ImageNet-R, but not ImageNetV2.[^zhou-2022-cocoop]
- A class-incremental test that jointly classified base and unseen classes averaged 69.13% for CoCoOp, compared with 65.55% for CoOp and 65.22% for zero-shot CLIP.[^zhou-2022-cocoop]
- On ImageNet, a 60-token static CoOp had roughly the same number of learned parameters as four-token CoCoOp with Meta-Net but lower new-class accuracy (65.34% versus 70.43%). This supports the paper's claim that the reported generalization gain is not explained solely by a larger parameter count in that experiment.[^zhou-2022-cocoop]

## Limits and trade-offs

- Instance-specific prompts require an independent text-encoder forward pass for each image, unlike CoOp's shared static prompts across a batch. The authors consequently report slower training, substantially greater GPU-memory use, batch size 1, and 10 training epochs; efficiency claims do not generalize beyond their implementation and hardware constraints.[^zhou-2022-cocoop]
- CoCoOp still trailed zero-shot CLIP on unseen classes in 7 of the 11 base-to-new datasets. Its gains are therefore evidence for this benchmark suite and setup, not a guarantee that learned dynamic prompts beat manual prompts or solve class-shift generalization.[^zhou-2022-cocoop]
- On DOSCO-2k contextual domain shifts, CoCoOp beat CoOp on four of seven datasets but CoOp had the higher average for three of the four evaluated backbones. This mixed result limits a broad claim of superior domain generalization.[^zhou-2022-cocoop]

## Relationships

- Extends: [CoOp context optimization](coop-context-optimization.md) by replacing its static learned context with a shared image-conditioned offset while keeping continuous prompt context and frozen CLIP encoders.[^zhou-2022-cocoop]
- Uses: [CLIP natural-language image pre-training](clip-natural-language-image-pretraining.md) as the frozen dual-encoder model whose image features condition prompts and whose text features form classifier weights.[^zhou-2022-cocoop]
- Compared with: [MaPLe multimodal prompt learning](maple-multimodal-prompt-learning.md), which couples deep language prompts to vision prompts rather than making text prompts instance-specific; MaPLe's paper reports a higher harmonic mean in its 11-dataset comparison, under its stated protocol.[^khattak-2023-maple]
- Extended by: [CasPL cascade prompt learning](caspl-cascade-prompt-learning.md), which first learns frozen multimodal boosting prompts through unlabeled-domain teacher distillation, then cascades them with CoCoOp's adapting prompts.[^wu-2024-caspl]
