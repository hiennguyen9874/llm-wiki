DFlash confines diffusion language modeling to speculative drafting: a small 5-layer block-diffusion drafter proposes a 16-token block in one forward pass conditioned on fused target-model hidden features, while the frozen autoregressive target verifies losslessly for over 6x speedup and up to 2.5x over EAGLE-3 on reported Qwen3 setups[^dflash-paper].

## Speedup framing

Per-token latency is `L = (T_draft + T_verify) / tau`, where `tau in [1, gamma+1]` is expected accepted tokens including the bonus token, and speedup is `eta = L_target / L`[^dflash-paper].

Autoregressive drafters pay `T_draft = gamma * t_step`, growing linearly with speculation budget and forcing very shallow drafters such as 1-layer EAGLE-3; diffusion drafters pay `T_draft = t_parallel` for the whole block, largely insensitive to `gamma` at moderate block sizes[^dflash-paper]. A 5-layer DFlash model generating 16 tokens reports both lower draft latency and higher acceptance than 1-layer EAGLE-3 generating 8 tokens[^dflash-paper].

## Inference design

Target prefill generates the first token and extracts hidden states from 5 layers uniformly sampled from the second to third-to-last target layer; they are concatenated and projected into a compact target context feature[^dflash-paper].

That feature is injected as persistent KV entries in every draft layer and reused across drafting iterations, rather than fused only at the draft input as in EAGLE-3 where the signal dilutes with depth[^dflash-paper]. Formally with shared projected target features `H_t` and draft states `H_d`[^dflash-paper]:

```text
H_t = RMSNorm(W_c [H^(l1); ...; H^(l5)])
Q_i = W_i^Q H_d
K_i = [W_i^K H_t; W_i^K H_d]
V_i = [W_i^V H_t; W_i^V H_d]
```

Target features bypass draft Q/output projections, attention updates, and FFN; extra parameters are only shared `W_c in R^(D x 5D)`, about 42 MB for D=2048 BF16, with about 40 MB + 8 MB activation at batch 1 / seq 2048 and under 400 KB temporary activation at block 16 decoding[^dflash-paper].

All masked positions in a block decode in parallel in one forward pass[^dflash-paper].

## Training

Drafters align block-diffusion predictions to a frozen autoregressive target, sharing and freezing target token embeddings and LM head so only draft Transformer layers train as a diffusion adapter[^dflash-paper].

Key modifications over standard block diffusion[^dflash-paper]:

- **Random anchor blocks:** sample anchor tokens from the response, start each block at an anchor, mask remaining `block_size-1` positions for parallel prediction. This matches inference where drafting conditions on a clean target-produced bonus token, diversifies target context, and beats uniform block partition on acceptance and speedup.
- **Joint sparse attention:** concatenate blocks into one sequence with Flex Attention mask — bidirectional within a block plus its injected target features, no cross-block attention — training multiple blocks per forward/backward pass.
- **Position-weighted loss:** `w_k = exp(-(k-1)/gamma)` emphasizes early block positions whose errors invalidate suffixes; reported to converge faster and higher than uniform weighting.
- **Bounded long-context cost:** fix masked-block count per sequence and resample anchors each epoch, keeping cost bounded with data augmentation.

Data mixture is about 800K samples from NVIDIA Nemotron Post-Training Dataset V2 plus CodeAlpaca, with responses regenerated by the target for alignment; reasoning-mode drafters train on target outputs with reasoning traces[^dflash-paper].

Reported hyperparameters: 5 layers (8 for Qwen3-Coder), block 16 (10 for LLaMA-3.1), 5 target features, AdamW 6e-4 for 6 epochs, grad clip 1.0, cosine with 0.04 warmup, max length 3072 (4096 for Qwen3-Coder), 512 anchors per sequence, loss-decay gamma 7 for block 16 / 5 for block 10 / 4 for block 8; online on-the-fly or offline cached target features[^dflash-paper].

## Why target conditioning is required

A 5-layer block-diffusion drafter without target features reports only modest 2–3x speedups, for example temp 0 GSM8K 2.83x / tau 3.38, Math500 3.73x / 4.61, AIME24 3.43x / 4.12, AIME25 3.35x / 4.07[^dflash-paper]. The paper's thesis is target hidden states already encode long-range semantics and future-token information, so the small drafter fuses reasoning from the target instead of reasoning from scratch[^dflash-paper].

## Performance

All figures below are source-reported, mostly H200 for Transformers and B200 for SGLang/vLLM, not independently verified[^dflash-paper].

### Instruct Qwen3, Transformers, thinking disabled

Block 16 versus EAGLE-3 tree 16 (matched budget) and tree 60 (max acceptance), draft steps 7 top-k 10, max 2048 tokens[^dflash-paper]:

- Greedy temp 0 average speedup: Q3-4B DFlash 4.91x / tau 6.54, Q3-8B 4.86x / 6.49; about 2.4x over EAGLE-3 (16) and above EAGLE-3 (60) with lower verification cost.
- Sampling temp 1 average: Q3-4B 4.24x / 5.69, Q3-8B 4.03x / 5.48; about 2.2x over EAGLE-3 (16).
- Q3-8B greedy peaks include MATH-500 6.08x / 7.87, AIME25 5.62x / 7.08, LCB 5.51x / 7.27; MT-Bench lower at 2.75x / 4.24.

### Reasoning Qwen3, thinking enabled

Trained on reasoning traces; temp 0 speedups roughly 4.2–4.6x, temp 1 roughly 3.6–4.0x, e.g. Q3-8B temp 0 GPQA 4.17x / 5.17, MATH-500 4.64x / 5.82, AIME25 4.51x / 5.74[^dflash-paper]. Valuable because long chain-of-thought dominates generation time[^dflash-paper].

### SGLang serving

Single B200, FA4 backend, Spec-v2 overlap, concurrency 1–32[^dflash-paper]:

- Qwen3-8B Math500: 1175 tok/s 5.1x at conc 1 down to 16076 tok/s 2.8x at conc 32, tau 8.01.
- Qwen3-8B HumanEval: 955 tok/s 4.2x down to 13116 tok/s 2.4x, tau 6.50.
- Qwen3-4B Math500: up to 4.8x, tau 8.01; Qwen3-Coder-30B-A3B HumanEval 3.5x–3.1x tau 8.09, LCB 2.6x–2.3x tau 6.42, MBPP 3.2x–3.1x tau 7.23.

LLaMA-3.1-8B-Instruct on SGLang Spec-v1 FlashInfer, same UltraChat+ShareGPT data as EAGLE-3, block 10 versus EAGLE-3 trees 10/60: DFlash wins all tasks and concurrencies, e.g. GSM8K 2.4x–1.6x tau 4.32, HumanEval 2.8x–1.8x tau 4.91, Alpaca 2.2x–1.4x tau 3.73[^dflash-paper].

Wider SGLang sweep at conc 8 reports DFlash over native MTP, e.g. Qwen3.5-9B Math500 7.3 / 3.5x versus MTP 6.7 / 1.7x; also covers Qwen3.5-4B/35B-A3B/27B, Qwen3-Coder-Next, and GPT-OSS-20B/120B[^dflash-paper]. vLLM Qwen3.5-9B reports Math500 849 tok/s 4.0x at conc 1 down to 9836 tok/s 1.9x at conc 32[^dflash-paper].

### Long-context adaptation

Base 4K-context Qwen3.5-27B drafter fine-tuned on 1.6K LongAlign-10K samples for 3 epochs preserves acceptance where base degrades, e.g. at 16K hotpotqa base 3.61 versus long 6.05, qasper 3.57 versus 6.00, gov_report 2.67 versus 3.81; at 32K gov_report 2.09 versus 3.56[^dflash-paper].

## Ablations

Qwen3 setups, 100K-sample ablations unless noted, greedy H200 except SGLang runs[^dflash-paper]:

- **Depth:** tau rises with layers but 5L best speedup — Math500 3L 4.69x/5.64, 5L 4.71x/5.99, 8L 4.64x/6.33; HumanEval 3L 3.90x/4.61, 5L 3.96x/4.94, 8L 3.96x/5.29.
- **Target features:** 5H beats 3H, e.g. Math500 4.69x/5.64 versus 4.49x/5.38, at linear growth in cached hidden-state storage for offline training.
- **Block size:** matched 16→16 beats 8→8 on math/code; block-8 fully accepts 35.7% of Math500 blocks suggesting underuse, while block-16 spreads acceptance higher. Train-16 generalizes to test-8 near train-8 levels, but train-8 does not generalize to test-16, enabling large-train small-infer plus future adaptive block scheduling under compute-bound batches.
- **KV vs input fusion, Qwen3-4B 5L block 8 tau/speedup:** AR DFlash-KV beats EAGLE-3-5L-input on GSM8K 4.8/2.4x vs 4.2/2.1x, HumanEval 4.6/2.3x vs 4.3/2.2x, MT-Bench 3.4/1.5x vs 3.1/1.4x; diffusion DFlash-KV beats diffusion-input 4.2/3.3x vs 3.5/2.9x GSM8K, 4.0/3.2x vs 3.5/2.9x HumanEval, 3.0/2.2x vs 2.6/2.0x MT-Bench. Diffusion matches AR acceptance at much higher speedup.
- **Sampling:** random anchors beat standard uniform masking, e.g. Math500 4.69x/5.64 vs 4.13x/4.94.
- **Loss decay:** exponential weighting converges faster and higher than uniform.

## Position in literature

EAGLE series exploits frozen-target features but drafts autoregressively with serial cost and tree verification; Medusa adds heads with tree attention; PARD trains small AR models to mimic parallel generation but lacks capacity for about 3x ceiling; DiffuSpec and SpecDiff-2 use massive ~7B diffusion drafters with high memory/latency for only 3–4x; TiDAR joint diffusion-AR thinking/talking is not lossless; Samragh et al. LoRA parallel drafting retains base for verification[^dflash-paper]. DFlash reframes diffusion as lightweight block drafters with verification guaranteeing quality, permitting aggressive single-step parallel denoising[^dflash-paper].

Code at `github.com/z-lab/dflash`, models in HF `z-lab/dflash` collection, project at `dflash.z-lab.ai`[^dflash-paper].
