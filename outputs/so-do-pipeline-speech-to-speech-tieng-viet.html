Speech-to-speech tiếng Việt

Một owner cho lượt hội thoại. ASR và TTS là service thay thế được; cầu text → speech nằm trọn trong TTS.

Thay engine, không sửa orchestrator

Hợp đồng asr.v1 / tts.v1 + Describe(); registry version và checksum; voice profile, lexicon và consent cho clone. Engine được pin theo session. Release qua license gate, conformance, offline → shadow (chỉ ASR) → canary → promote; rollback bằng config.

Đo ở client, giữ chất lượng dưới tải

v2v mục tiêu mềm: P50 ≤ 1.5 s · P95 ≤ 2.5 s. Output gate thường quyết định latency. Warmup trước ready; queue có giới hạn, backpressure và fallback từ cache. Log content-free, trace nối theo turn / revision / generation / chunk.

Nguồn: Thiết kế pipeline speech-to-speech tiếng Việt · v2, 2026-10-14 · §§4–9.

Rút gọn: API và engine sidecar gộp trong mỗi service; registry và observability mô tả bằng ghi chú. Không vẽ các mở rộng P2/P3: speaker lock, denoise, streaming/two-pass ASR, L2, SFU và telephony. Giả định WebRTC kết thúc tại orchestrator; played offset WebRTC là ước lượng bảo thủ, cần kiểm chứng.

VieNeu là baseline đề xuất, có license mâu thuẫn; deployment thương mại phải chặn đến khi làm rõ.

Default light: white-smoke / jet-black / atomic-tangerine. HTML + SVG inline, không JavaScript; Google Fonts tùy kết nối, có fallback hệ thống.
