# Course profile: general

Default profile for any domain without a dedicated profile.

## Practice

Choose the form that fits the domain and the cited evidence:

- **Worked example:** a concrete case solved step by step, with each step's reasoning.
- **Procedure:** numbered steps with inputs, expected results, and safety or validity conditions.
- **Exercise or case study:** a realistic scenario with guiding questions and a model answer.
- **Code:** include only when the domain is computational; use the language the sources use and keep it minimal and runnable.

## Verification

- Self-check questions with answers that cite the course sections or sources.
- For procedures or code, an observable expected result the reader can compare against.
- For factual claims that change over time, the date or version the claim was valid for.

## Trade-offs

Compare alternatives on criteria supported by the sources: cost, risk, effort, reliability, or applicability. Do not invent quantitative comparisons.

## Vocabulary

Use the terms the cited sources use; add a gloss on first use.
