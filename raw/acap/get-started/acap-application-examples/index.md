Version: ACAP version 12

Axis provides several ACAP application examples with an open-source license through the [acap-native-sdk-examples](https://github.com/AxisCommunications/acap-native-sdk-examples) GitHub repository. There, you'll find at least one example demonstrating the use of each API in the ACAP Native SDK. Along with its [API](https://developer.axis.com/acap/reference/supported-apis/) reference, these examples provide all the information you need to integrate a specific API into your own application. There are also some larger examples combining multiple APIs, such as the [object-detection-yolov5](https://github.com/AxisCommunications/acap-native-sdk-examples/tree/main/object-detection-yolov5) example, that uses [Video capture API (VDO)](https://developer.axis.com/acap/reference/supported-apis/#video-capture-api-vdo), [Machine learning API (Larod)](https://developer.axis.com/acap/reference/supported-apis/#machine-learning-api-larod), [Parameter API](https://developer.axis.com/acap/reference/supported-apis/#parameter-api), and [Bounding Box API](https://developer.axis.com/acap/reference/supported-apis/#bounding-box-api).

Each example is explained and categorized by use case in the [README](https://github.com/AxisCommunications/acap-native-sdk-examples/blob/main/README.md) file of the repository. To learn even more about a specific example, see the README file of the example, where you'll find instructions for how to build and run the example application.

## Report issues

We are committed to providing relevant and functioning examples, so feel free to reach out with issues and feedback about the examples through the [issues](https://github.com/AxisCommunications/acap-native-sdk-examples/issues) section on GitHub.
